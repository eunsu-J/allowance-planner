# 계획서.md — 예산 재조정 가계부 (가계부J)

대학생 및 사회초년생이 생활비 초과 등 예외 상황이 발생했을 때, 현재 상황에 맞게 예산을 다시 계산하고 계획을 재조정할 수 있도록 돕는 웹앱입니다.

---

## 1. 입력값 (사용자가 처음 넣는 값)
- **내용**: 
  - 이번 달 총 예산 (가용 예산): 사용자가 직접 입력 및 언제든 수정 가능
  - 이번 달 지출 예산 설정:
    - 매일 소모되는 1일 생활비 (예: 15,000원)
    - 예상외 지출 예산 (예: 100,000원)
  - **예산 차액 계산**: 이번 달 총 예산 - 이번 달 지출 예산
- **완료 기준**: 
  - [지출변경] 버튼을 통해 일일 생활비와 예상외 지출을 입력하면, '이번 달 지출 예산'과 '예산 차액(여유 자금)'이 즉시 자동 계산되어 출력된다.

---

## 2. 초안 생성 (앱이 먼저 만들어 주는 계획)
- **내용**:
  - 총 예산과 지출 예산, 그리고 예산 차액을 토스형 카드로 명확하게 시각화
  - 1일 권장 생활비 = 남은 가용 예산 ÷ 남은 일수
  - 예산 소모율(%)과 한 달 잔여율(%) 병기
- **완료 기준**: 
  - 메인 화면 상단에 총 예산, 지출 예산, 예산 차액, 남은 생활비가 한눈에 표시된다.

---

## 3. 실행 기록 (사용자가 날마다 남기는 것)
- **내용**:
  - 카테고리: **생활비**, **예상외 지출** 2개
  - **날이 넘어갈 때마다 매일 생활비 자동 감축**: [다음 날로 이동] 클릭 시 지출 예산에 설정된 매일 생활비가 현재 생활비 잔액에서 자동으로 감축되어 기록됨
  - 어제 생활비 가져오기 퀵 버튼 제공
  - 텍스트 입력창 한글 우선 지원 (`lang="ko"`, IME 최적화)
  - 지출 항목명, 금액, 선호도(1점~5점)
  - 날짜별 누적 이력 관리: 날짜 배지와 함께 전체 날짜 및 오늘만 보기 필터 지원
- **완료 기준**: 
  - [다음 날로 이동] 시 매일 생활비가 현재 생활비 잔액에서 자동 차감되고, 지출 등록 시 추가 소비액이 차감된다.

---

## 4. 모니터링 (한눈에 보여 줄 것)
- **내용**:
  - 이번 달 남은 예산, 오늘 지출액, 누적 예산 소모율(%), 한 달 잔여율(%)
  - 실시간 소비 상태에 따른 안내
- **완료 기준**: 
  - 실제 소비액과 남은 예산이 프로그레스 바 및 텍스트로 실시간 갱신된다.

---

## 5. 재조율 (계획대로 안 됐을 때 다시 맞추는 규칙)
- **내용**:
  - [지출변경] 및 [예산 변경]을 통해 언제든 내 상황에 맞게 생활비 계획과 총 예산을 재설정 가능.
- **완료 기준**: 
  - 변경 시 전체 계산 결과가 즉각 연동되어 바뀐다.

---

## 추가로 확정한 규칙
- 진입 파일은 단일 `index.html`로 구성하며 HTML/CSS/JS만 사용한다.
- 모바일 360px 폭에서 가로 스크롤 없이 완벽히 동작한다.
- 모든 금액은 한국 원화 포맷(예: "12,000원")으로 쉼표를 표기한다.
- 상단에 `[다음 날로 이동]`과 `[처음부터 다시]` 테스트 버튼을 항상 제공한다.
- 모든 데이터는 `localStorage`(`kakeiboJ_` 접두사)에 저장된다.
- 앱 이름은 '가계부J'로 확정한다.
- 한 달 기준 기간은 매월 1일 ~ 말일(30일 기준)로 한다.
- 카테고리는 **'생활비'**, **'예상외 지출'** 2개만 사용한다.
- 반복 지출 입력 편의를 위해 '어제 생활비 가져오기' 기능을 제공한다.
- 지출 입력창에 한글 우선 모드(`lang="ko"`)를 지원한다.
- 체험 샘플 데이터 및 긴급 재조율 추천 박스를 삭제하고 깔끔한 실사용 UI로 전환한다.
- '이번달 설정 예산' 아래에 **'이번달 지출 예산'**을 표시하고, **[지출변경]** 버튼으로 매일 소모되는 생활비와 예상외 지출을 입력하게 한다.
- **'이번달 예산 - 이번달 지출 예산'**을 계산하여 여유 자금/차액을 명확히 출력해 보여준다.
- **날이 넘어갈 때마다(다음 날로 이동 시) 매일 생활비가 현재 생활비 잔액에서 자동으로 감축되도록 연동한다.**
