# 가계부J (Budget Planner)

대학생 및 사회초년생을 위한 생활비·예상외 지출 예산 관리 웹앱

## 🌟 주요 기능
1. **이번 달 설정 예산 및 지출 예산 관리**
   - 총 가용 예산 입력 및 언제든 수정 가능
   - 매일 소모되는 1일 생활비(30일 환산)와 예상외 지출 예산 직접 기입
   - `이번달 예산 − 지출 예산` 실시간 차액(여유 자금/초과) 출력
2. **지출 기록 및 날짜별 누적 관리**
   - `🥗 생활비` / `⚡ 예상외 지출` 2종 카테고리
   - 어제 입력한 생활비 1초 만에 가져오기 (`[📋 어제 생활비 가져오기]`)
   - 날짜가 지나도 지출 내역이 날짜 배지와 함께 영구 누적 보관 (전체/오늘 필터 지원)
3. **직관적인 모니터링**
   - 토스 스타일의 직관적인 예산 소진 프로그레스 바
   - `예산 소진율(%)`과 `한 달 잔여율(%)`을 함께 비교하여 과소비 방지
4. **상시 테스트 도구**
   - `[📅 다음 날로 이동]`: 가상 날짜 +1일 넘기기
   - `[🔄 처음부터 다시]`: 전체 데이터 초기화 후 재시작

## 🛠️ 기술 스택
- HTML5, CSS3, JavaScript (Pure Vanilla Web)
- 로컬 브라우저 `localStorage` 기반 상태 저장
